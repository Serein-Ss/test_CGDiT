# 第二阶段检索合同与来源边界

日期：2026-09-14。目标是 `data/derived/pilot30.csv` 的 30 个 MAGNDATA 标识，针对尚未覆盖的 24 条逐条进行有界检索，不声称穷尽全部文献。

检索以标识对应的化学式为主，结合原始温度、magnetic、neutron、Néel 等词；对找不到的记录补查 MAGNDATA 精确页面或论文题名。原温度仅用于检索线索，不提供给提取模型。括号式化学式展开为标识中的常用化学式；不把不同化学计量比、氧含量或多型合并。

来源优先级：原论文/作者机构记录、原论文作者上传版本、MAGNDATA 精确记录。论文引言对既有测量的引用明确标为 cited_background。没有验证原始测量时不升级为直接实验标签。

端点：出版社和作者机构的论文页面、arxiv.org/abs/<id>、www.cryst.ehu.es/magndata/index.php?this_label=<id>。网页检索结果提供的是可获取片段，不是每篇论文全文。不存在可用于本次搜索的全量计数端点；完成标准为逐条记录检索状态，并明确缺口。

机器可读证据清单见 `evidence/pilot30_sources_v2.json`，含目标记录、来源 URL、可确认的 DOI、短引文、归属说明和局限。助手注释未提供给 Intern 提取器，避免用自己的答案作为输入。

直接打开 MAGNDATA 1.689、1.495、1.281、0.279、1.775、1.68、2.11 页面均失败；0.617 的索引结果可用。没有关闭 TLS 验证，也没有把邻近标识 2.12 的 TbMg 结构当作目标 2.11。LuMn2Ge2 检索到了非原始托管的 508 K 文献线索，TbMg 检索到了混合磁序线索，Mn3As 检索到大量 Mn3As2 或不同结构的结果；本轮均未纳入可信提取输入。

最终取得片段的 27 条中，仍包含原始测量待追溯、跨样品数值不一致和上下文不足的记录。`evidence_available=true` 只表示存在片段，不能替代“已核验”“独立金标准”或“可训练”。

结构核查目前限于元数据线索：KMnSb 的数据库 ID 精确匹配；Na2MnTeO6 的 P-31c（163）与本地 SG 相符，但没有坐标核验。其 R-3 多型的无长程磁序结果不转移到该条记录。其余材料仍须原始 mcif、样品条件和文献对应核查。

本工作采用 Scientific Agent Skills 中的检索记录规范；项目提案已有相关软件来源说明。它不是磁性物理结论的证据。
