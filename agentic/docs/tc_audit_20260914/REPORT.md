# Tc 模型审计（2026-09-14）

检查了现有 CSV、训练/评估代码、已完成实验日志与原始论文。未启动训练、GPU 推理或 DFT；未修改数据、模型或训练代码。

## 主要结论

当前模型具有一定的既有标签预测/富集能力，但标签不是经过核验的纯居里温度数据，不能据此宣称能筛选高居里温度铁磁/亚铁磁材料。先做证据驱动的数据修复，比增加主动学习 DFT 更优先。

1. 训练集 0.639_Mn2Au 的 tc=1000、0.108_Mn3Ir 的 tc=960 对应反铁磁材料；原始研究明确讨论 Néel 温度。Mn2Au 的 1000 也不能不加核验地视为精确实验转变温度，原文讨论高于 1000 K 的外推结果。来源：https://www.nature.com/articles/ncomms3892 。整个数据集尚未逐条确定转变类型。
2. 测试集 0.782_NdScO3 的 tc=953。原始论文摘要明确报告相变温度 0.953 K，存在 1000 倍数值冲突。来源：https://doi.org/10.1016/S0921-4526(96)01067-8 。本地缺少原始抓取表及完整溯源链，无法确定是抓取、单位转换还是其他环节导致；本次未直接修正测试标签。
3. 按 CIF 字符串完全相同进行保守检查，有23组、50条记录对应不同温度，涉及多个阈值两侧冲突。见 identical_cif_label_conflicts.csv。比如 CeMnAsO 为347/35/7 K，EuMnBi2为315/19 K。这不必然是实验错误，可能是多个磁子晶格或多个相变；但当前不含磁序和转变类型的输入无法辨识这些标签。不可直接平均或取最大温度。
4. 训练/验证/测试分别1023/122/139条；>=300 K分别111/11/16；>=500 K分别28/2/6；>=700 K分别9/1/4。这些只是当前数值标签计数，不等于可信高居里温度样本数。训练和验证合计6条0 K需回源核实，不能直接判断为非磁性。

## 代码与评估边界

当前划分按pretty_formula分组，manifest记录组间无重叠；标准化统计来自训练集；MoE硬阈值只在验证集上选。没有发现这几处明显的测试标签泄漏。三种seed只改变训练随机性，数据划分仍固定。

DiffusionBackboneRegressor使用原子种类、坐标和晶格，在t=0预测，不输入磁矩方向、磁子晶格或相变类别。原始预处理转普通CIF及后续原胞约化保留几何结构，不能保留未编码的磁序差异。目录名magndata及列名tc本身不能证明标签是Curie temperature。

旧notebook已有RF/GBDT/SVR/Ridge实验，采用与现有严格对照不同的数据与随机按行划分，不能直接和当前139条测试集对比。更换为RF不是尚未尝试过的新方案。

本地 output 下缺少日志指向的magndata_tc_benchmark、magndata_tc_moe产物目录；日志来自旧/root/private_data/...路径。故本次从保存日志核对指标，未重新推理，也无法重新计算逐候选top-k、子家族误差或修正标签后的指标。

## 低计算成本路线（建议，尚未执行）

1. 先做文献证据审计：按material_id回源，把转变类型、磁序、原始数值/单位、精确值或上下界、文献出处补齐；优先>=300 K、0 K、重复冲突及单位异常。不调用DFT。
2. 生成单独的curated版本，保留原始数据和修订记录；明确区分FM/FiM的Curie、AFM的Néel、其他相变与未知。发现测试标签问题后冻结统一修订规范，再重评所有模型，不因模型残差大而删除样本。
3. 以实验文献和开放数据补高温FM/FiM样本。只有成分的条目用于成分模型；只有可靠匹配原子坐标的条目才进入结构模型，不能把一个化学式的温度赋给任意同成分结构。
4. 优先测试冻结预训练骨干+小预测头/少量末层微调，配合分组交叉验证；这仍有小额训练成本但不增加量子化学标签计算。相比继续增加专家数量更直接针对小样本全量微调的过拟合风险。
5. 将生成改为有文献依据的母结构及邻近成分探索，现有Tc分数只作弱参考或暂时移出奖励；综合结构相似性、独立稳定性检查与证据覆盖。继承结构或相似成分不能保证继承Tc，输出只能称候选。
6. 不用LLM或代理模型的未经验证预测生成真值；不把未报告样本当非磁性。最终少量候选仍需独立验证，但无需在每轮为大批结构运行DFT+Monte Carlo。
